# CraveHub — Food Delivery, Done Deliciously

A modern, elegant food delivery web app built with **React 18 + Vite + Tailwind CSS + Framer Motion**.

## Features

- **Home** — animated hero with floating dishes, cuisine marquee, featured kitchens, testimonials
- **Restaurant discovery** — live search, cuisine / rating / delivery-fee filters, 3 sort orders
- **Restaurant pages** — category tabs, add-to-cart with quantity steppers, favourites
- **Cart drawer + cart page** — promo codes (`CRAVE20`, `FLAT200`), order summary
- **Checkout** — validated address form, card / wallet / cash on delivery
- **Live order tracking** — animated rider route map, journey timeline that advances in real time
- **Order history & favourites** — persisted in localStorage
- Fully responsive, unique motion design throughout

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

All restaurant names, menus and photography are original content created for this concept project.
